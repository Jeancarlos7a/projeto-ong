# ONG Solidariedade

Projeto desenvolvido durante a disciplina de Desenvolvimento Front-End para Web.

## Sobre o projeto

A aplicação representa uma ONG fictícia e possui páginas para apresentação da organização, visualização de projetos sociais e cadastro de colaboradores.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Vite
- Git e GitHub

## Funcionalidades

- Navegação entre as páginas
- Exibição de projetos sociais
- Formulário de cadastro
- Armazenamento de dados no localStorage
- Layout responsivo
- Modo de alto contraste
- Recursos básicos de acessibilidade

## Estrutura do projeto

O projeto foi organizado em arquivos HTML, CSS e JavaScript. O JavaScript também foi dividido em módulos para separar as diferentes funcionalidades da aplicação.

## Como executar

Para executar o projeto localmente, primeiro instale as dependências:

npm install

Depois, inicie o projeto com:

npm run dev

## Versionamento

O projeto utiliza Git e GitHub para controle de versão. As branches `main`, `develop` e `feature/` são utilizadas para organizar o desenvolvimento.
